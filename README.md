# AI Website Auditor

An AI-powered website auditing agent built with Next.js that analyzes websites for SEO, content, technical, accessibility, and UX issues and provides actionable recommendations for improvement.

## 🚀 Features

- Website URL analysis
- Multi-page website crawling
- SEO analysis
- Content analysis
- Technical SEO checks
- Broken link detection
- Image alt-text analysis
- Open Graph and Twitter Card checks
- Sitemap and robots.txt detection
- Accessibility checks
- AI-powered website analysis
- Priority recommendations
- Page-level improvement suggestions
- Audit history
- Report export
- Evaluation and benchmarking tools

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- OpenAI API
- Cheerio
- Node.js
- Tailwind CSS

The crawler collects the website facts first, while the AI layer interprets those facts and provides recommendations.
